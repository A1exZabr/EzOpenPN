# Совместимость

## Серверы

Первая версия предназначена только для amd64:

| Система | Статус контракта |
|---|---|
| Ubuntu 22.04 LTS | Поддерживается установщиком |
| Ubuntu 24.04 LTS | Основная рекомендация |
| Debian 12 | Поддерживается установщиком |
| Debian 13 | Поддерживается установщиком |

Для публичного выпуска каждая строка должна дополнительно пройти чистую установку в одноразовой VM. Требуется напрямую назначенный публичный IPv4. ARM, NAT без назначенного адреса и системы без systemd не поддерживаются.

## Клиенты

В таблицу подтверждённых клиентов попадают только приложение и точная версия, которые в реальном испытании:

1. импортировали общую ссылку;
2. подключились через VLESS + Reality поверх XHTTP;
3. подключились через Hysteria2 с Salamander;
4. прекратили соединение после отключения профиля.

До завершения внешней матрицы подтверждённых строк нет. Это намеренное ограничение: название приложения или успешный handshake не считаются доказательством совместимости. Репозиторий нельзя делать публичным, пока таблица и подписанные результаты не заполнены.

Приложение должно поддерживать XHTTP с `packet-up`, Reality, Hysteria2, Salamander и импорт HTTPS подписки. Если оно поддерживает только один транспорт, отдельную ссылку можно импортировать вручную, но такое приложение не закрывает полную release-матрицу.

## Браузеры панели

Панель использует обычные HTML формы и небольшой JavaScript только для копирования. Релизный тест проверяет текущие Chromium на desktop и мобильном viewport, keyboard navigation и отсутствие серьёзных ошибок доступности. Конкретная версия фиксируется вместе с browser evidence каждого выпуска.
