# Политика безопасности

## Поддерживаемые версии

Текущий публичный предварительный выпуск: v0.1.9. Сообщения о его уязвимостях принимаются через закрытый канал ниже. Полная внешняя release-матрица ещё не завершена, поэтому проект не заявляет готовность стабильного выпуска. После его появления исправления безопасности будут готовиться для последнего поддерживаемого стабильного выпуска.

## Закрытое сообщение

Не создавайте публичный issue с описанием уязвимости. Используйте GitHub Private vulnerability reporting:

<https://github.com/A1exZabr/EzOpenPN/security/advisories/new>

Если закрытая форма временно недоступна, не публикуйте секреты и дождитесь её восстановления. Личных email, мессенджеров и внешних форм проект не использует.

## Что приложить

- версию EzOpenPN и серверную систему;
- минимальные безопасные шаги воспроизведения;
- ожидаемое влияние;
- подтверждение, что тест выполнялся на принадлежащем вам одноразовом экземпляре.

Не отправляйте admin login, session cookie, полные ссылки, QR-коды, UUID, private key, master key, SQLite, backup archive, публичный адрес рабочего сервера или данные других людей.

## Обработка

Отчёт сначала подтверждается на изолированном окружении. Исправление получает regression test, локальные security gates и проверку затронутого release artifact. Публикация деталей откладывается до доступного исправленного выпуска.
