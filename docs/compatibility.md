# Совместимость

## Серверы

Первая версия предназначена только для amd64:

| Система | Статус контракта |
|---|---|
| Ubuntu 22.04 LTS | Поддерживается установщиком |
| Ubuntu 24.04 LTS | Основная рекомендация |
| Debian 12 | Поддерживается установщиком |
| Debian 13 | Поддерживается установщиком |

Для v0.1.9 все четыре системы прошли автоматическую VM-матрицу с 1 ГиБ RAM без swap. Это лабораторные проверки, не испытание всех провайдеров. Требуется напрямую назначенный публичный IPv4. ARM, NAT без назначенного адреса и системы без systemd не поддерживаются.

## Клиенты

В таблицу подтверждённых клиентов попадают только приложение и точная версия, которые в реальном испытании:

1. импортировали общую ссылку;
2. подключились через VLESS + Reality поверх XHTTP;
3. подключились через Hysteria2 с Salamander;
4. прекратили соединение после отключения профиля.

До завершения внешней матрицы подтверждённых строк нет. Это намеренное ограничение: название приложения или успешный handshake не считаются доказательством совместимости. Поэтому v0.1.9 публикуется как предварительный, а не как полностью проверенный стабильный выпуск.

### Где взять приложение для пробной установки

| Устройство | Официальный источник кандидата для проверки |
|---|---|
| Android | [Hiddify](https://github.com/hiddify/hiddify-app/releases) |
| iPhone / iPad | [Happ: сайт разработчика со ссылками на магазин](https://www.happ.su/) |
| Windows | [v2rayN](https://github.com/2dust/v2rayN/releases) |
| macOS / Linux | [Hiddify](https://github.com/hiddify/hiddify-app/releases); вне обязательной матрицы этого выпуска |

Это ссылки для самостоятельной проверки, **не список подтверждённо совместимых версий**. Выбирайте актуальный обычный выпуск, не beta/nightly, подходящий своей системе. Поддержка одного протокола ещё не означает поддержку всей комбинации EzOpenPN. После импорта отдельно проверьте оба варианта. Если A не работает, не считайте проверку B доказательством полной совместимости и наоборот.

Не скачивайте приложения из рекламных объявлений и случайных архивов. Следуйте ссылкам разработчика на нужный магазин или установщик. Названия кнопок и доступность приложений могут меняться. Как импортировать профиль, описано [здесь](profiles.md).

Приложение должно поддерживать XHTTP с `packet-up`, Reality, Hysteria2, Salamander и импорт HTTPS подписки. Если оно поддерживает только один транспорт, отдельную ссылку можно импортировать вручную, но такое приложение не закрывает полную release-матрицу.

## Браузеры панели

Панель использует обычные HTML формы и небольшой JavaScript только для копирования. Релизный тест проверяет текущие Chromium на desktop и мобильном viewport, keyboard navigation и отсутствие серьёзных ошибок доступности. Конкретная версия фиксируется вместе с browser evidence каждого выпуска.
