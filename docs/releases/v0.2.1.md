# EzOpenPN v0.2.0: предварительный выпуск

Личный сервер защищённых подключений с русской панелью и установкой одной командой. Главное в этой версии: сервер снаружи выглядит как обычный сайт на своём IP-адресе, а транспорт A больше не показывает вложенный TLS. Домен по-прежнему не нужен.

## Начать

Откройте [инструкцию с нуля](https://github.com/A1exZabr/EzOpenPN/blob/main/docs/getting-started.md). Для v0.2.0 используйте точную команду из [README](../../README.md#установка-одной-командой): она закреплена за этим выпуском. Пакеты лежат в GitHub Releases, контейнеры в публичном GHCR; Forgejo для установки больше не нужен.

## Что изменилось

- **Selfsteal по IP.** Reality больше не выдаёт себя за чужой сайт (раньше это был, например, `www.apple.com`). Всё, что не является профилем сервера, получает его собственная заглушка с сертификатом Let's Encrypt на публичный IPv4. Сканер, браузер и проверка провайдера видят согласованные адрес, сертификат и страницу.
- **Подключение без SNI.** Клиенты, как браузер, открывающий адрес по IP, не отправляют имя сайта. В ссылке профиля вместо имени указан IP сервера.
- **VLESS + Reality с Vision.** Транспорт A переведён с XHTTP на RAW с `xtls-rprx-vision`: вложенное TLS-рукопожатие приложения не видно. Trojan и VLESS без Vision не используются.
- **Заглушка.** Отвечает по TLS 1.2 и TLS 1.3 с HSTS, без заголовка `Server` и без HTTP/3, на любое запрошенное имя. Текст и оформление выводятся из ключа узла: одинаковые после обновлений, разные у разных серверов. Надпись EzOpenPN из маскировки Hysteria2 убрана.
- **Порт 80.** Отвечает `301` на `https://SERVER_IP/`; продление сертификата работает как раньше.
- **Закрытые служебные порты.** Наружу по-прежнему открыты только `80/tcp`, `443/tcp`, `443/udp` и `9443/tcp`. Управление Xray, статистика Hysteria2 и панельный backend доступны только внутри сервера.
- **Проверки `doctor`.** Новые строки `camouflage`, `http_redirect` и `published_ports` подтверждают всё перечисленное на живом сервере.
- **Проще установка.** Установщик больше не перебирает чужие сайты командой `tls ping`, поэтому исчезли ошибки `E_TARGET_LIST` и `E_TARGET_UNAVAILABLE`.
- **Безопасность зависимостей.** Go 1.26.9, `golang.org/x/net` 0.61.0, `golang.org/x/crypto` 0.58.0, `urllib3` 2.8.0, Hysteria2 2.13.0 и обновлённые базовые образы.

## Обновление с v0.1.9

Ключи Reality, UUID профилей, пароли Hysteria2 и пароль панели сохраняются. Файлы конфигурации прежней версии на диске не меняются, поэтому неудачное обновление откатывается на v0.1.9.

После обновления у каждого профиля меняется ссылка транспорта A (Vision вместо XHTTP). Приложения, которые обновляют общую ссылку-подписку, получат её сами. Если ссылку A вставляли вручную, импортируйте её заново. Ссылка транспорта B не меняется.

Пока v0.2.0 предварительный, существующий сервер не переходит на него автоматически: обновление и повторный запуск установщика используют только стабильный канал. После перевода v0.2.0 в стабильные запустите на сервере короткую команду установки из GitHub: она найдёт существующую установку и выполнит обновление с резервной копией.

## Ограничения

Это **pre-release**. Владелец сообщил, что v0.1.9 на его сервере подключала устройства и передавала трафик. Для v0.2.0 транспорт A изменился, поэтому структурированные испытания обоих транспортов в фиксированной и мобильной сети, отзыв профиля и проверка точных версий Android, iOS и Windows-клиентов ещё впереди. Локальные тесты, CI и VM-матрица их не заменяют.

Перед выпуском проверено локально: тесты панели, установщика и shell, рендер конфигурации, принятие итогового `config.json` настоящим Xray 26.3.27 и Caddyfile настоящим Caddy 2.11.4, а также стенд с подключением Vision без SNI, ответом заглушки по TLS 1.2 и TLS 1.3 и перенаправлением `301`.

Поддерживаются amd64/x86_64, Ubuntu 22.04/24.04 и Debian 12/13. ARM и общий IP за NAT не поддерживаются. Работа при любых блокировках не обещается.
