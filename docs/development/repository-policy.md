# Политика репозитория EzOpenPN

EzOpenPN развивается как самостоятельный проект с собственной историей. Репозиторий создаётся из текущего корневого коммита, без импорта, зеркалирования и статуса форка. До первого создания у локальной копии не должно быть внешних Git-адресов.

На всём этапе разработки репозиторий остаётся закрытым. Открытая публикация допустима только после полного прохождения проверок плана выпуска: тестов, контейнерной сборки, проверки установки на чистой системе, аудита содержимого и проверки отсутствия секретов.

Основная ветка называется `main`. Состояние удалённой `main` после первичной отправки должно в точности совпадать с проверенным локальным коммитом. Описание проекта должно быть нейтральным: «Самостоятельный сервер защищённых подключений».

В историю запрещено добавлять реальные адреса серверов, ключи, пароли, токены, файлы окружения и данные пользователей. Демонстрационные адреса берутся только из диапазонов, зарезервированных для документации.
